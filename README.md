# Divya Poojari — Portfolio

A responsive personal portfolio built with React, Vite, and Lucide icons.

## Included
- Hero / personal introduction
- About and professional highlights
- Experience timeline
- Selected projects
- Technical skills grouped by domain
- GitHub, LinkedIn and email links
- Responsive mobile navigation
- Dark/light theme toggle
- Accessible semantic sections and metadata

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Most portfolio content is defined near the top of `src/main.jsx`. Styling is in `src/styles.css`.

## Source of portfolio content

Content is based on the supplied resume and intentionally avoids adding unsupported employers, metrics, projects, or claims.
